# Aurora PostgreSQL Logical Replication & CDC

## Overview

This project demonstrates a production-inspired PostgreSQL logical
replication architecture based on hands-on experience supporting
Aurora PostgreSQL environments.

The implementation demonstrates:

- PostgreSQL logical replication
- pgoutput
- Publications
- Subscriptions
- Replication slots
- WAL-based change propagation
- Replication monitoring
- Data validation
- Manual data backfill
- Conflict-safe data insertion
- Migration and recovery considerations

The public implementation uses sanitised configuration and a
reproducible PostgreSQL environment. No production credentials,
customer data, proprietary code, or production endpoints are included.
